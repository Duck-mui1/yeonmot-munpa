# 연못문파 · 도깨비의 세계

연못문파 문파원을 위한 모바일 커뮤니티 웹앱(PWA) **프로토타입**입니다.
빌드 도구 없이 순수 HTML / CSS / JavaScript로만 동작하고, GitHub Pages 같은 정적 호스팅에 그대로 올릴 수 있습니다.

## 구성

| 파일 | 내용 |
| --- | --- |
| `index.html` | 로그인·가입 화면과 5개 탭(홈 · 문파채팅 · 문파앨범 · 문파원 · 내정보)의 뼈대 |
| `css/style.css` | 연못 · 연꽃 · 물결 · 반딧불 색과 질감을 담은 스타일 |
| `js/data.js` | 공지 · 일정 · 쿠폰 · 사냥 팁 · 문파원 · 앨범 · 대화 예시 데이터 |
| `js/art.js` | 홈 배너와 앨범 장면을 그리는 자체 제작 SVG 일러스트 |
| `js/app.js` | 화면 렌더링, 로그인 흐름, 채팅 · 좋아요 · 출석 등 로컬 동작 |
| `manifest.json` | PWA 설치 정보(이름, 아이콘, 테마 색) |
| `sw.js` | 오프라인에서도 열리도록 파일을 기억하는 서비스 워커 |
| `icons/` | 앱 아이콘(PNG)과 파비콘(SVG) |

## 실행 방법

정적 파일이라 별도 설치 없이 열 수 있습니다.

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일로 바로 열어도 화면은 보이지만, 서비스 워커와 설치 기능은 http(s) 주소에서만 동작합니다.

## GitHub Pages 배포

1. 저장소에 이 폴더의 파일을 그대로 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 저장합니다.
3. `https://<아이디>.github.io/<저장소>/` 로 열립니다. (모든 경로가 상대 경로라 하위 폴더 배포에서도 안전합니다.)

## 고칠 때

파일을 고친 뒤 `sw.js`의 `CACHE_NAME`(예: `yeonmot-munpa-v1` → `-v2`)을 올리면, 이미 앱을 설치한 기기도 새 화면을 받습니다.

## 체험용 로그인

- 초대 코드: `YEONMOT`
- 또는 로그인 화면의 **체험 모드로 둘러보기** 버튼

## 데이터와 개인정보

- 이름 · 전화번호 · 이메일 · 주소 · 실명을 코드와 예시 데이터에 넣지 않았습니다.
- 닉네임과 PIN은 로그인 화면의 형식 확인에만 쓰고 **PIN은 저장하지 않습니다.**
- 대화 · 출석 · 좋아요 · 설정은 브라우저의 `localStorage`에만 남고 서버로 전송되지 않습니다.
- 예시 쿠폰 코드와 문파원 목록은 모두 지어낸 프로토타입용 데이터입니다.

## 아직 붙이지 않은 것

- 실제 다중 사용자 채팅 · 사진 업로드 · 회원 인증(서버/DB 필요)
- 게임 계정 연동, 푸시 알림

프로토타입은 화면과 흐름을 확인하는 단계입니다. 위 기능은 다음 단계에서 붙일 수 있습니다.
