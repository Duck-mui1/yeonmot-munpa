# 연못 · 도깨비의 세계

연못 문파원을 위한 모바일 커뮤니티 웹앱(PWA)입니다.
빌드 도구 없이 순수 HTML / CSS / JavaScript로 동작하고, 데이터는 Supabase(Postgres)에 담깁니다.
**체험 모드**는 서버 없이 예시 데이터로 바로 둘러볼 수 있고, **실제 문파 모드**는 Supabase 프로젝트에 연결해
가입 · 출석 · 채팅 · 앨범 · 쿠폰 · 문주(관리자) 기능을 함께씁니다.

## 연결 정보

`js/db.js` 맨 위 두 줄만 바꾸면 다른 Supabase 프로젝트로 옮길 수 있습니다.

```js
var SUPABASE_URL = 'https://cwkyvpummgwelylcaayy.supabase.co';
var SUPABASE_KEY = 'sb_publishable_…';   // 공개용(publishable) 키 — 브라우저에 있어도 되는 키
```

> 비밀 키(service_role / secret key)는 절대 이 파일에 넣지 마세요.
> 앱은 공개 키만 쓰고, 모든 읽기·쓰기는 `schema.sql`의 RPC와 RLS 설계로 지켜집니다.

## 처음 한 번만 하면 되는 설치 (문주 = 준형 님)

1. **DB 설치** — Supabase 대시보드 → **SQL Editor** → 새 쿼리에 `supabase/schema.sql` 전체를 붙여 넣고 **Run**.
   - 바로 가는 링크: <https://supabase.com/dashboard/project/cwkyvpummgwelylcaayy/sql/new>
   - 이미 설치한 뒤 구조를 바꿨다면, 파일 맨 끝의 `drop` 블록(주석)을 풀어 지우고 다시 실행하세요.
2. **첫 가입 = 문주** — 앱에서 **가입하기** → 닉네임 · PIN(4자리) · 초대 코드 `YEONMOT` 을 넣습니다.
   - 문주가 한 명도 없을 때의 첫 가입자는 **자동으로 문주(admin)** 가 됩니다. 따로 설치 코드를 넣을 필요가 없습니다.
   - (문주가 이미 있는데 자리를 잃었다면 `select private.set_setup_code('…')` 후 `bootstrap_admin` 으로 복구합니다.)
3. **초대 코드 바꾸기** — 내정보 → **문주 도구 → 초대 코드 확인 · 변경**.
   - 처음 값 `YEONMOT` 은 공개된 예시 코드이니, 문파원을 들이기 전에 새 코드로 바꿔 두세요.
   - 코드는 **대소문자를 가리지 않습니다** (`yeonmot` / `YEONMOT` 모두 통과, 저장은 항상 대문자).
4. **이미 쓰고 있다면 v2 마이그레이션** — SQL Editor에서 `supabase/migration-v2.sql` 전체를 실행하세요.
   - 프로필 그림(avatar) · 홈 **공략**(guides)이 한 번에 준비됩니다. 여러 번 실행해도 기존 데이터는 그대로입니다.
   - 새로 설치하는 경우에는 `schema.sql` 만 실행하면 v2 내용이 이미 들어 있습니다.
   - **쿠폰 코드 한글**과 **문파원 자리비움** 게시판은 `supabase/migration-v3.sql` 하나로 함께 준비됩니다.
     (쿠폰 코드 3~24자 — 한글 · 영문 · 숫자 · `-` · `_` / 자리비움 — 로그인한 문파원 누구나 등록, 삭제는 운영진만)
   - **운영진의 대신 자리비움 등록**은 `supabase/migration-v4.sql` 로 준비됩니다.
     (문주·부문주가 다른 문파원을 골라 대신 올리거나, 아직 가입하지 않은 문파원 이름을 직접 적어 올립니다)
   - **프로필 그림 '오리'** 는 `supabase/migration-duck.sql` 하나로 준비됩니다.
     (`update_my_avatar` 프리셋 화이트리스트에 `preset:duck` 만 더합니다)
   - **문파앨범 '글(선택)'** 은 `supabase/migration-album-text.sql` 하나로 준비됩니다.
     (제목을 비워 둘 수 있게 하고 — 사진만 올리기, 글은 300자까지)
   - **문파컨텐츠(예전 이름: 일정)와 매주 반복**은 `supabase/migration-clan-contents.sql` 하나로 준비됩니다.
     (홈 섹션 이름 변경 + `repeat_weekly` · `repeat_weekdays` 칸, `admin_create_event` · `admin_update_event` 에 두 파라미터 추가)
   - **🍡 경단만들기 문파 랭킹**은 `supabase/migration-gyeongdan.sql` 하나로 준비됩니다.
   - 점수 상한을 1억으로 넓히려면(경단 도감 점수표) `supabase/migration-gyeongdan-score-cap.sql` 을 한 번 더 실행하세요.
     (문파원마다 최고 점수 한 줄을 담는 표 + 점수 제출 · 랭킹 조회 RPC. 실행 전에도 게임은 이 기기 최고 점수로 그대로 돌아갑니다)
5. **문파원 초대** — 바뀐 초대 코드를 알려 주면, 문파원은 **가입하기**에서 닉네임 · PIN · 초대 코드로 들어옵니다.
   - 로그인은 **닉네임 + PIN** 만 씁니다(초대 코드는 가입할 때만).
   - PIN 5회 오입력 시 잠시 잠깁니다(최대 5분).

## 문주(관리자) 기능

`member_role = 'admin'` 인 계정에만 보입니다.

| 위치 | 기능 |
| --- | --- |
| 홈 · 공지 | `+ 공지 추가`, 공지별 `고정/고정 해제` · `삭제` |
| 홈 · 문파컨텐츠 | `+ 문파컨텐츠 추가`, 컨텐츠별 `문파컨텐츠 삭제`, `한 번만 / 매주 반복` |
| 홈 · 쿠폰 | `+ 쿠폰 추가`, 쿠폰별 `쿠폰 삭제` |
| 홈 · 문파원 자리비움 | 자리비움별 `×` 삭제 (운영진만 · 올린 본인이어도 일반 문파원은 불가) · 모달에서 **대상 문파원 고르기**(다른 문파원 대신 · 미가입자 이름 직접 입력) |
| 문파원 | 문파원별 `운영진으로 / 문파원으로` · `내보내기` · `차단`, 내보낸 사람은 `다시 들이기` |
| 문파채팅 | 각 메시지의 `지우기` (본문이 즉시 비워져 모두에게서 사라짐) |
| 문파앨범 | 각 사진의 `×` 삭제 (본인 사진도 같은 버튼으로 삭제) |
| 내정보 | `문주 도구` — 초대 코드 확인 · 복사 · 변경, 문파원/내보냄/차단 수 |

## 프로필 그림

| 어디서 | 무엇을 |
| --- | --- |
| 내정보 → **프로필 그림** | 연못 일러스트 9종(연꽃 · 잉어 · 개구리 · 반딧불 · 달빛 · 연잎 · 거북 · 등불 · 오리)을 **3×3** 으로 고르기 |
| 내정보 → **내 사진 올리기** | 폰 사진을 가운데 정사각형으로 잘라 **128×128 JPEG(10~25KB)** 로 줄여 저장 |
| 내정보 → **기본 글자로** | 닉네임 첫 글자로 되돌리기 |

- 고른 그림은 **문파채팅 말풍선 · 문파원 목록 · 내정보 · 공지/앨범 작성자**에 함께 보입니다.
- 그림은 앱이 직접 그리는 SVG 라서 사진과 달리 용량이 늘지 않습니다(저장 값은 `preset:duck` 같은 이름).
- 저장 값은 `preset:lotus` 같은 이름이거나 65,000자 이하의 `data:image/…;base64` 입니다.
  서버는 `update_my_avatar` 로 본인 것만 바꾸며, 사진은 48KB 를 넘으면 거절합니다.
- 체험 모드에서는 이 기기에만 저장됩니다.

| 지금 상황 | 화면 | 안내 |
| --- | --- | --- |
| 이미 앱으로 실행 중 (`display-mode: standalone`) | 로그인 · 홈 | 설치 배너를 숨기고, 내정보 → **앱으로 쓰기** 에 `이미 앱으로 열려 있어요` |

- 홈 상단 배너는 `×` 로 닫을 수 있고, 닫은 상태는 이 기기에 기억됩니다(브라우저별로 따로 기억).
- 설치 안내는 `js/app.js` 의 `installEnv()` · `installBannerHtml()` · `installCardHtml()` 에 모여 있습니다.
- 서비스 워커 캐시는 `sw.js` 의 `CACHE_NAME`(현재 `v23`)으로 올려 새 화면이 바로 반영되게 합니다.

## 🍡 경단만들기 (미니게임)

로그인한 뒤 상단 헤더의 **🍡 미니게임** 버튼으로 어느 탭에서나 바로 엽니다.

- **놀이 방식** — 위에서 경단을 떨어뜨리고, 같은 단계 경단 두 개가 닿으면 다음 단계로 합쳐집니다(수박게임식).
  위쪽 **데드라인**(판 높이의 8.5%)을 넘게 쌓이면 그 자리에서 게임 오버입니다.
- **경단 11단계** — 박쥐단 · 사마귀단 · 쥐단 · 뱀단 · 호랑이단 · 돼지단 · 곰단 · 자서귀단 · 황요호단 · 산군대호단 · 백운단.
  위에서 떨어지는 것은 1~5단계뿐이고, 나오는 비율도 45% · 28% · 16% · 8% · 3% 로 「루팡문파」와 같습니다.
- **그림** — 보내 주신 **「도깨비의 세계」 1~11단계 고화질 시트**에서 한 알씩 오려낸 **배경 투명 PNG**(`assets/gyeongdan/tier-1.png` ~ `tier-11.png`, 372~406px)를
  몸통 반지름에 맞춰 그립니다. 그림마다 투명 여백이 달라서 그림 속 몸통 원을 재어 두고
  (`SPRITE_BALL` · `SPRITE_OFF`) 몸통 가운데가 회전축에 오도록 크기와 위치를 맞춥니다 — 보이는 몸통은 기준 반지름의 0.907배(이전 그림과 같은 크기).
  바깥 흰 배경은 테두리에서 이어진 곳만 지워 백운단·자서귀단의 흰 털과 뱀단·호랑이단의 흰 주둥이가 뚫리지 않고,
  흰 테두리(프린지)는 알파로 풀어 없앴습니다. 귀 · 더듬이 · 갈기는 원형 충돌 크기와 어울리게 살짝 밖으로 나옵니다.
  PNG 를 아직 받지 못했거나 실패하면 예전의 Canvas 벡터 그림이 그대로 대신 나옵니다.
- **판 크기·비율** — 놀이판은 화면 폭을 꽉 채우고(가로:세로 = 444:480, 「루팡문파」 경단만들기와 같은 비율),
  경단 반지름은 판 너비 360 기준 비율(1단계 19.2 → 11단계 74.2)을 따라 폰 크기가 달라도 같은 손맛이 납니다.
- **그림 출처** — 경단 이미지의 저작권은 「도깨비의 세계」에 있으며, 권리자 요청 시 즉시 삭제됩니다.
  놀이판 힌트 아래와 「경단 도감」 맨 아래에 이 안내를 함께 적어 둡니다.
- **점수 (경단 도감 그대로)** — 2단계 +10 · 3단계 +21 · 4단계 +45 · 5단계 +120 · 6단계 +360 · 7단계 +1,120 ·
  8단계 +3,580 · 9단계 +11,800 · 10단계 +40,100 · 11단계 +140,000. 백운단 두 개가 합쳐지면 둘 다 사라지며 **+280,000점**.
- **도구 — 절구공이 하나 (무제한)** — **백운단만** 지울 수 있고(+1,000점), 다른 경단을 누르면 “백운단만 지울 수 있어요!” 라고 알려 줍니다.
  도구를 고른 뒤 놀이판의 경단을 누르면 발동하고, **취소** 버튼이나 `Esc` 로 풀 수 있습니다.
- **물리** — 「루팡문파」 경단만들기와 같은 방식·같은 값으로 다시 썼습니다(외부 물리 라이브러리 없이 직접).
  중력은 판 높이의 15배(px/s²), 무언가에 닿아 있는 동안은 3.5배로 약해져 겹친 경단이 서로를 밀어내지 않습니다.
  반발은 거의 없고(경단끼리 0.04 · 벽 0.25 · 바닥 0.17), 경단은 24방향으로 살짝 울퉁불퉁한 도형(반지름 0.72~1.01배)이라
  서로 파고들어 앉고 굴러가다 자리를 잡습니다. 120Hz 고정 스텝 · 겹침 보정 8회 · 0.24초 잠들기.
  옆으로 굴러가면 속도에 맞춰 **구르는 회전**이 붙고, 멈춘 뒤에도 굴러간 각도 그대로 얼굴이 남습니다.
- **조작** — 모바일은 좌우로 끌어 조준한 뒤 손을 떼면 떨어지고(탭 한 번도 됩니다), PC는 마우스로 같은 방식입니다.
- **이어하기** — 진행 중인 판은 이 기기(localStorage)에 남아, 창을 닫거나 다른 탭을 보고 와도 이어집니다.
- **문파 랭킹** — 한 판이 끝나면 최고 점수와 도달한 단계를 서버에 보내고, 문파원 모두의 순위를 봅니다.
  마이그레이션 전(PGRST202)에는 게임이 이 기기 최고 점수로 그대로 돌고, 랭킹 탭에만 안내가 나옵니다.

## 공략 (유튜브 영상)

- 홈의 **공략**은 유튜브 영상 카드가 **2×2** 로 보이고, 카드를 누르면 유튜브(새 탭)로 열립니다.
- 썸네일은 `https://i.ytimg.com/vi/{video_id}/hqdefault.jpg` 를 씁니다.
- **올리기**: 로그인한 문파원 **누구나** `+ 공략 추가` → 유튜브 주소를 붙여 넣으면 영상 ID 를 자동으로 찾아 미리 보여 줍니다.
  (`youtu.be/…`, `youtube.com/watch?v=…`, `youtube.com/shorts/…`, 11자 영상 ID 모두)
- **삭제**: **올린 본인** 또는 **운영진(문주 · 운영진)** 만 `×` 버튼이 보이고, 서버(`delete_guide`)도 같은 규칙으로 확인합니다.
- 4개를 넘으면 `공략 더 보기` 로 이어서 볼 수 있습니다. 체험 모드의 4개는 예시 카드(연못 그림)입니다.

## 쿠폰 코드

- `+ 쿠폰 추가` 에서 받는 것은 **쿠폰 코드**와 **유효기간(선택)** 두 가지입니다. 유효기간을 비우면 카드에 `기한 없음` 이 붙습니다.
  (내용·보상 칸은 없앴습니다. DB(`admin_create_coupon`)는 1~60자를 요구하므로 앱이 내부에서 `-` 를 넣어 보내고, 카드에서는 `-` 를 빈 값으로 보고 그리지 않습니다.)
- 카드에는 **유효기간 배지 · 쿠폰 코드 + 복사 버튼 · 쿠폰 삭제(운영진만)** 가 보입니다. 이전에 내용·보상을 넣어 둔 쿠폰은 그 값이 남아 있을 때만 함께 보입니다.
- 코드는 **한글 · 영문 · 숫자 · `-` · `_` 3~24자** 이고, **한글 · 영문 · 숫자로 시작**해야 합니다.
  예) `연꽃2026` · `새문파원환영` · `한글-coupon_01` · `LOTUS2026`
- 앞뒤 공백은 지우고 영문은 대문자로 저장하며, 같은 코드인지 볼 때도 대소문자를 가리지 않습니다.
- 홈 쿠폰 카드의 `복사` 버튼으로 코드를 그대로 복사해 게임 안 등록창에 붙여 넣습니다.
- 서버(`admin_create_coupon`)와 DB 제약이 같은 규칙으로 확인하고, 앱 화면도 같은 규칙으로 먼저 걸러 냅니다.

## 문파원 자리비움

- 홈 맨 아래(공략 아래 · 이 연못에 대해 위)에 **문파원 자리비움** 게시판이 있습니다.
- **등록**: 로그인한 문파원 **누구나** `+ 자리비움 등록` → 시작일 · 종료일 · 이유(1~60자).
  - **시작일은 오늘(한국 시간) 이후만** 고를 수 있고(`min`), 오늘 이전이면 화면과 서버(`create_absence`)가 모두 거절합니다.
  - **종료일은 시작일과 같거나 뒤**여야 합니다(화면 · 서버 · 테이블 제약).
- **운영진(문주 · 부문주)은 다른 문파원 대신** 올릴 수 있습니다. 모달 맨 위 **대상 문파원** 에서
  - `나 (내 닉네임)` — 기본값, 내 자리비움
  - **문파원 목록** — 가입한 다른 문파원을 골라 대신 등록(카드에 그 문파원 닉네임·아바타)
  - **직접 입력 (아직 사이트 미가입)** — 이름을 2~20자로 적어 대신 등록(카드에 그 이름, 아바타는 첫 글자)
  - 일반 문파원에게는 이 선택이 보이지 않고, 서버(`create_absence`)도 남의 자리비움은 42501로 거절합니다.
- **보기**: 작성자 아바타 · 닉네임, 기간(`11.24 ~ 11.28`), 이유.
  - 오늘이 기간 안이면 **자리비움 중**, 아직 시작 전이면 **예정** 배지.
  - 대신 올린 항목은 **대리** 배지와 `○○ 님이 대신 올렸어요` 가 함께 보입니다.
  - 종료일이 지난 항목은 목록에서 빠지고, 진행 중 · 예정 항목이 **시작일 순**으로 먼저 옵니다.
- **삭제**: **운영진(문주 · 운영진)** 만 `×` 버튼이 보이고, 서버(`delete_absence`)도 운영진이 아니면 42501로 거절합니다.
  (올린 본인이라도 일반 문파원이면 삭제할 수 없습니다.)
- 체험 모드에는 예시 2건이 들어 있습니다.

## 실시간

- 채팅 · 공지 · 문파컨텐츠는 Supabase Realtime(`postgres_changes`) 구독으로 바로 반영됩니다.
- 상단에 `문파원 N명 · 실시간` 배지가 뜨고, 연결이 끊기면 `다시 연결 중` 으로 바뀝니다.
- 구독이 막힌 환경(회사망 등)에서도 화면은 그대로 동작하고, 탭을 옮길 때 최신 내용을 다시 불러옵니다.

## 앨범 사진

- 문파원은 하루 10장까지 올릴 수 있습니다.
- 올리기 전에 브라우저에서 **긴 변 1,280px · 800KB 이하**로 자동 축소합니다(JPEG).
- 서버(`create_album_post`)는 data URL 1,130,000자 · 원본 800KB 초과를 거절합니다.
- **사진을 누르면 원본을 크게 봅니다** — 상세 보기에서 사진(또는 `크게 보기` 배지)을 누르면
  화면을 가득 채우는 뷰어가 열립니다. 두 손가락으로 확대·축소, 두 번 눌러 확대/원래대로, 끌어서 이동,
  `−`·`1:1`·`+` 버튼(1:1 은 원본 픽셀), `×` 나 `Esc`, 사진 바깥을 눌러 닫습니다.
  뷰어는 저장된 원본(최대 1,280px)을 그대로 씁니다 — 카드의 작은 그림을 늘려 보는 것이 아닙니다.

### 글 (선택)

- 사진을 올릴 때 **글을 함께 남길 수 있습니다** — 안 적어도 그냥 올라갑니다.
- 글은 **300자까지**이고, 입력칸 아래에 `0 / 300` 글자 수가 함께 보입니다.
- 여러 줄로 적으면 그 줄바꿈 그대로 보입니다.
  - 앨범 카드: 두 줄까지 보이고 나머지는 `…` 로 줄입니다.
  - 상세 보기(사진을 눌렀을 때): 적은 글이 전부 보입니다.
- 글을 안 적은 사진은 카드·상세 보기 어디에도 빈 칸이나 `-` 없이 사진과 작성자만 보입니다.
- 글은 화면에 글자로만 그려집니다(`escapeHtml`) — `<img …>` 같은 HTML 을 적어도 그대로 글자로 보입니다.
- 글 기능 이전에 올린 사진(제목만 있던 사진)은 그 제목이 그대로 카드에 보입니다.
- 서버 규칙 — `create_album_post(p_token, p_title, p_image_data, p_caption, p_image_mime)`
  - 제목은 비워도 됩니다(빈 값 허용, 40자까지). 앱은 글의 첫 줄을 제목 자리에 함께 보내 구버전 서버와도 호환됩니다.
  - 글(설명)은 300자까지 — 넘으면 `22023` 으로 거절합니다.
  - 빈 제목을 허용하려면 이미 쓰는 DB에 `supabase/migration-album-text.sql` 을 한 번 실행해야 합니다.
    (실행 전에는 글 없이 올리기가 서버에서 거절되고, 앱이 그때만 "지금은 글을 한 줄이라도 적어야" 하고 안내합니다)

## 실행 방법

정적 파일이라 별도 설치 없이 열 수 있습니다.

```bash
# 이 폴더에서
python3 -m http.server 8000
# 브라우저에서 http://localhost:8000 접속
```

`index.html`을 파일로 바로 열어도 화면은 보이지만, 서비스 워커 · 설치 기능 · Supabase 호출은 http(s) 주소에서만 동작합니다.

## GitHub Pages 배포

1. 저장소에 이 폴더의 파일을 그대로 올립니다.
2. 저장소 **Settings → Pages**에서 Branch를 `main`, 폴더를 `/ (root)`로 저장합니다.
3. `https://<아이디>.github.io/<저장소>/` 로 열립니다. (모든 경로가 상대 경로라 하위 폴더 배포에서도 안전합니다.)

## 고칠 때

- 화면을 고친 뒤 `sw.js`의 `CACHE_NAME`(지금은 `yeonmot-munpa-v18`)을 올리면, 이미 앱을 설치한 기기도 새 화면을 받습니다.
- 서버 규칙을 바꾸면 `supabase/schema.sql` 도 함께 고치고 SQL Editor에서 다시 실행해야 합니다.
- 확인:
  ```bash
  node --check js/app.js && node --check js/db.js && node --check sw.js
  ```

## 체험 모드

- 로그인 화면의 **체험 모드로 둘러보기** 버튼, 또는 아무 닉네임이나 눌러 들어가기.
- 서버에 아무것도 보내지 않고, 대화 · 출석 · 좋아요는 이 기기의 저장 공간에만 남습니다.
- 체험 모드에서는 문주 도구가 보이지 않습니다(문파를 실제로 관리하려면 실제 문파 모드로 들어가야 합니다).

## 데이터와 개인정보 (제로 원칙)

- 이름 · 전화번호 · 이메일 · 주소 · 실명을 받지 않습니다. 저장하는 사람 정보는 **닉네임과 PIN 해시**뿐입니다.
- PIN 은 bcrypt 해시로만 저장되고, 어떤 RPC/뷰로도 원문이 나가지 않습니다.
- 로그인 세션은 32바이트 랜덤 토큰이며 DB 에는 SHA-256 해시만 저장합니다(30일 만료).
- 화면 설정 같은 기기 기록은 브라우저 `localStorage` 에만 남습니다.
- 예시 쿠폰 코드와 체험 모드의 문파원 목록은 모두 지어낸 데이터입니다.
