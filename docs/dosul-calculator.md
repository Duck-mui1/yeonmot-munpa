# ⚔️ 도술 계산기 — 도술 효율 · 평타 빈 시간

연못 앱 하단 **「⚔️ 도술」 탭**에 있는 계산기입니다. 8칸에 도술을 넣으면
**쿨타임이 비어 평타를 치는 시간**과 **초당 피해(DPS)** 를 계산합니다.

## 어떻게 계산하나

1. 도술마다 **쿨타임**(초)과 **시전(동작) 시간**(초)이 있습니다.
2. 자동 사냥은 쿨이 돌아온 도술을 **칸 순서(1번 → 8번)** 대로 씁니다.
3. 시전하는 동안에는 다른 도술을 쓸 수 없습니다(그 시간만큼 묶입니다).
4. 쓸 수 있는 도술이 하나도 없을 때 **평타**를 칩니다.
   → 이 시간이 「평타 치는 빈 시간」입니다.
5. 쿨타임은 **시전을 시작한 순간**부터 흐릅니다.

계산은 0.05초 눈금이 아니라 **이벤트(쿨이 돌아오는 순간) 단위**로 나눠서
`평타 시간 + 도술 시전 시간 = 전투 시간` 이 정확히 맞습니다.

## 데이터 출처

`js/dosul-data.js` — 도깨비지지(kkaebi.gg) 도술 빌더의 공개 데이터(2026-11 확인).
문파청(munpa.kr)·도깨비허브(metahub.wiki)·덱깨비(dekkaebi.com)와 교차 확인했습니다.

| 칸 | 뜻 |
| --- | --- |
| `cd` | 쿨타임(초) |
| `ct` | 시전(동작) 시간 = 선행 시전 + 동작 시간 |
| `pc` | 선행 시전(초) |
| `ch` | 최대 차지 시간(초) — 「최대 차지로 계산」을 켜면 더해집니다 |
| `mv` | 전체 애니메이션 길이(초) — 시전 기준을 바꿀 때 씁니다 |
| `c` | PvE 총 피해 계수(%) — 1회 계수 × 타격수 |
| `h` | 타격 수 |

도술 106개(일반 94 + 궁극기 12), 12계열의 신식 효과 문구도 함께 들어 있습니다.
`은신`·`최후의 저항` 은 공개된 동작 시간이 없어 0.5초로 두고 화면에 「추정」으로 표시합니다.

## 신식 · 궁극기

기본 1~5번 칸에 **같은 계열 3개**를 넣으면 그 계열 **신식**이 열리고 **궁극기(R)** 가
자동으로 붙습니다. 신식 효과는 게이지가 차면 발동하는 것이라 계산기에서는
토글로 켜고 끕니다(3개를 넣으면 자동으로 켜짐).

| 계열 | 계산기에 반영한 효과 |
| --- | --- |
| 절명 | 궁극기 쿨 -6초 · 궁극기 피해 +125% |
| 연타 | 피해 +20% |
| 강타 | 피해 +10% · 10회마다 도술 쿨 초기화 |
| 척살 | 도술 쿨 -20% |
| 저격 | 저격 피해 +45% · 궁극기 피해 +75% |
| 주술 | 매 시전마다 도술 쿨 -0.2초 · 궁극기 피해 +90% |
| 파멸 | 14회마다 도술 쿨 초기화 · 피해 +20% |
| 강인 | 보호막(딜 영향 없음) |
| 기동 | 20회마다 궁극기 쿨 초기화 · 궁극기 피해 +50% |
| 기만 | 3회마다 그 도술 쿨 -50% |
| 헌신 | 이로운 효과 +30%(딜 영향 없음) |
| 제압 | 궁극기 쿨 -9초 · 피해 +6% |

## 화면

- **인기 프리셋 4개** — 실제 공략 조합(파멸 8개 · 무과금 파멸+헌신 · 저격 단일 · 절명+저격).
- **도술 8칸** — 칸을 누르면 계열 필터·이름 검색으로 고릅니다. ▲▼ 로 순서를 바꿉니다.
  칸마다 그 도술의 게임 아이콘이 크게 붙습니다.
- **내 스펙 조정** — 전투 시간(30/60/120초), 전체 쿨감(%), 평타 1회 시간·계수,
  도술 사이 간격, 차지 도술 최대 차지, 궁극기 우선, 시전시간 기준(동작/전체 애니메이션),
  도술별 쿨·시전·계수 직접 수정(돌파·각성 반영).
- **결과** — 맨 위에 평타 빈 시간(초·%)과 도술 가동률, 그 아래 DPS·총 계수·발동 횟수·평타 비중,
  도술별 발동·기여 표, 초반 30초 시전 타임라인.
- **순서 추천** — 두 칸 맞바꾸기·한 칸 옮기기를 모두 계산해 DPS가 가장 높은 순서를 찾습니다.

## 📌 문파 공유 조합

계산 결과 아래 **💾 이 조합 문파에 공유하기** 로 제목·메모와 함께 저장합니다.
저장되는 것: 장착 8칸, 계산 설정(전투 시간·쿨감·시전 기준·평타·신식 토글·도술별 수정값),
그때의 **평타 빈 시간(%)** 과 **초당 피해(%)**.

- 로그인 상태 → 문파 서버(Supabase)에 저장. 문파원 누구나 목록에서 보고 한 번에 불러옵니다.
- 체험 모드 / 마이그레이션 전 → 이 기기(localStorage `ym.dosul.shared.v1`)에만 저장하고 안내를 띄웁니다.
- 지우기는 **올린 본인 + 운영진(admin·officer)** 만. 한 사람당 30개까지.
- 서버: `supabase/migration-dosul.sql` (`save_dosul_build` · `list_dosul_builds` · `delete_dosul_build`).

## 도술 아이콘

칸·고르기 창·결과 표·타임라인 범례에 **게임 도술 아이콘**이 붙습니다.

- 파일: `assets/dosul/<도술 id>.webp` — 100×100 webp 106개(궁극기 12개 포함), 총 664KB.
- 출처: 도깨비지지(kkaebi.gg) **도술 도감**이 쓰는 게임 아이콘을 내려받아 로컬에 두었습니다.
  (외부 사이트에 매번 요청하지 않아 오프라인·로딩 속도에 유리합니다)
- 목록·그리기: `js/dosul-icons.js` (`YM_DOSUL_ICONS.html(id, {cls, size, lazy})`).
  목록에 없는 id 는 계열 색 글자 타일로 대신합니다(안전 폴백).
- 고르기 창은 106줄이라 `loading="lazy"` 로 보이는 줄만 불러오고,
  칸·결과 표·범례는 바로 불러옵니다.
- 아이콘의 저작권은 「도깨비의 세계」에 있으며, 권리자 요청 시 즉시 삭제될 수 있습니다.
  화면 맨 아래(`.ds-credit`)에 같은 문구를 둡니다 — 경단만들기와 같은 방식입니다.
